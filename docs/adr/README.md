# Architecture decision records

ADRs capture decisions that future contributors should not have to reconstruct.
They are immutable after acceptance except for small factual corrections. When
a decision changes, add a new ADR and mark the old one as superseded.

Use sequential filenames such as `0002-provider-registry.md` with these fields:

```text
# ADR 0002: Title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Supersedes: optional ADR number

## Context
## Decision
## Consequences
## Validation
```
